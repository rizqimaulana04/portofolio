KPJ PDF Auto Renamer.

StreamlitGoogle ColabPDF

01 / RINGKASAN

Tentang
proyek ini.

Berawal dari kebutuhan seorang teman yang bekerja di PT Swakarya Insan Mandiri: mengganti nama ratusan hingga ribuan file dengan mencocokkan nama dan isi dokumennya. Proyek ini dibuat sebagai solusi atas kebutuhan tersebut, bukan sebagai klaim proyek resmi perusahaan.

TAMPILAN APLIKASI

Lihat karya lebih dekat.

Klik gambar untuk memperbesar.

Tampilan asli aplikasi. Antarmuka mencantumkan batas 2.000 PDF per batch; ini bukan hasil uji performa. PDF hasil pemindaian memerlukan OCR, yang terlihat nonaktif pada tampilan ini.

02 / PROSES & IMPLEMENTASI

Dari masalah.
Menuju solusi.

01

Pekerjaan berulang

Membuka dokumen dan mengganti namanya satu per satu menjadi pekerjaan yang memakan waktu ketika jumlah file bertambah. Tujuannya adalah mempersingkat proses penamaan file berdasarkan informasi di dalam PDF.

02

Eksperimen di Google Colab

Versi awal dikerjakan di Google Colab untuk mengeksplorasi proses membaca isi PDF dan mengganti nama file yang sesuai.

03

Dari notebook ke aplikasi

Mengembangkan aplikasi Streamlit dengan unggahan ZIP berisi PDF dan file Excel. Pengguna memeriksa kolom Excel sebelum memproses pencocokan nomor KPJ. Antarmuka menjelaskan bahwa PDF asli tetap disertakan jika tidak cocok atau gagal dibaca.
