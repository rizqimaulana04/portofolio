# Muhammad Rizqi Maulana - Portfolio

Website portofolio profesional berbahasa Indonesia dan Inggris dengan halaman studi kasus, galeri screenshot, dan visualisasi skripsi.

## Teknologi

HTML, CSS, JavaScript

## Menjalankan proyek

Buka `index.html` melalui server statis, atau letakkan folder di XAMPP dan buka `http://localhost/portofolio/`. Tidak memerlukan database.

Pilihan bahasa disimpan di browser. Isi halaman utama ada di `index.html` dan `translations.js`; isi detail proyek menggunakan `project-translations.js`.

Foto profil tersedia di `assets/rizqi-portrait.png`. Kontak email, GitHub, dan LinkedIn sudah tersedia. Dokumen CV PDF masih perlu ditambahkan.

## Isi repository

Repository berisi kode sumber dan aset presentasi. Konfigurasi produksi, database operasional, backup, data pelanggan, session, dan upload privat tidak disertakan.
